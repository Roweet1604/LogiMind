# 0039: Public demo on Render (API) and Vercel (console)

Date: 12 Nov 2026. Status: accepted (asked for by the team: a permanent link the mentor can open, zero cost).

## Decision
- **API on Render, free web service** (`render.yaml` at the repo root, root dir `backend`). Start command
  `uvicorn app.main:app --host 0.0.0.0 --port $PORT`; health check `GET /health` (new, `{"status": "ok"}`;
  `/api/health` keeps the details). SQLite in `/tmp/logimind-data`, inline worker (one service, no separate
  worker), `LOGIMIND_DRIVER_LINK_SECRET` generated by Render. Python 3.14.7, the version the suite runs on locally.
- **Public demo:** new flag `LOGIMIND_PUBLIC_DEMO=1`, only together with `LOGIMIND_DEMO_MODE=1`. It turns demo mode on
  whatever the bind host, and `GET /api/demo/session` hands the demo tenant's key to any caller. The local-only rules
  of decision 0029 are unchanged when the flag is not set (existing tests untouched). Docker Compose,
  `.env.example` and the Dockerfile still never enable demo mode.
- The free plan has **no persistent disk**: every deploy or wake-up starts with an empty database, and start-up seeds
  the SYNTHETIC demo tenant with its three plans again (normal queue, solvers and validator).
- **CORS:** `FRONTEND_URL` is added to the allowed origins (trailing slash ignored).
- **Console on Vercel** (root dir `frontend`): `VITE_API_URL` is the API address (old `VITE_API_BASE` still read);
  `frontend/vercel.json` rewrites every path to `index.html` so refreshing `/plans/...` works. When `VITE_API_URL` is
  set, the "server down" text says the free host may be waking up instead of "run start-dev.bat".
- `FRONTEND_URL` is read from the environment, else from the `backend/.env` file (so a plain `uvicorn` start, e.g.
  behind a Cloudflare tunnel on the laptop, also picks it up).
- `backend/requirements.txt` is pinned to the versions the suite passed with.

## Why
A link that works without the team's laptop, at zero cost (CLAUDE.md invariant 12). Render's free plan sleeps and
wipes the disk, so the demo data must rebuild itself.

## Limits
- Anyone with the link can use the demo tenant (create plans, imports, driver links, webhooks; the SSRF guard and
  rate limiter still apply). The server must hold nothing but synthetic demo data. Other tenants stay isolated
  (tested in `tests/test_public_demo.py`).
- After about 15 idle minutes Render stops the service; the first request then waits about a minute.
- 512 MB RAM on the free plan: memory use of OR-Tools + the solver process there is not measured.
- No Ollama on Render, so the copilot shows "no local model" unless a viewer pastes a free hosted key (decision 0033).
- The driver PWA is not deployed.
